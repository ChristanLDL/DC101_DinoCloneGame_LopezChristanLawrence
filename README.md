# DC101_DinoCloneGame_LopezChristanLawrence
This is a inspired game from Chrome Dino Jump.

Title: Dino Jump Clone


Project Description:

This is a simple browser-based endless runner game, a clone of the classic Chrome Dino Runner. The game is built using pure HTML Canvas, CSS and JavaScript, inspired by the Chrome Dino Runner.


How to Play:

* **Start the Game:** `SPACE BAR` key or `ArrowUp` key.
* **Jump:** `SPACE BAR` key or `ArrowUp` key.
* **Restart:** `SPACE BAR` key or `ArrowUp` key after the Game Over screen appears.

Technology Used:

* **HTML5:** (Canvas, Semantic Structure)
* **CSS3**
* **JavaScript (ES6)**


To run the game:

* Open `index.html` in any modern web browser.
